2019 Sales Report

This project cleans and analyzes 2019 sales data using Python and visualizes insights with Power BI.
Multiple monthly CSV files are automated into a single clean dataset for analysis and reporting.

Tools

Python (Pandas), Jupyter Notebook, Power BI

Highlights
	•	Automated data cleaning and transformation
	•	Feature engineering (total sales, city, day, month)
	•	Interactive Power BI dashboard for sales insights

How to Run

Run AUTOMATED_SALES.ipynb, then open SALES_VISUALISATION.pbix in Power BI and refresh the data.
